Sobre o projeto

O Job Finder é uma aplicação web desenvolvida para facilitar a divulgação e a busca de oportunidades profissionais na área de tecnologia.

A plataforma permite consultar vagas cadastradas, pesquisar oportunidades pelo título e publicar novas vagas com informações sobre a empresa, salário, descrição e contato.

Importante: esta página é uma apresentação do projeto e um guia de execução. Para utilizar as funcionalidades da aplicação, é necessário executar o servidor localmente seguindo as instruções abaixo.

Tecnologias utilizadas

Node.js

Ambiente de execução JavaScript no servidor.

Express

Framework utilizado para criar o servidor e as rotas.

Express Handlebars

Renderização dinâmica das páginas da aplicação.

Sequelize

ORM utilizado para comunicação com o banco de dados.

SQLite

Banco de dados utilizado para armazenar as vagas.

Bootstrap

Framework utilizado na construção da interface.

Como executar o projeto

Siga os passos abaixo para executar a aplicação em sua máquina.

1
Instale os pré-requisitos

Antes de começar, você precisa ter o Node.js e o npm instalados em sua máquina.

Baixar Node.js

2
Clone o repositório

Abra o terminal e execute o comando: 

git clone https://github.com/Lazaro277/job-finder.git
3
Acesse a pasta

Entre no diretório do projeto: 

cd job-finder
4
Instale as dependências

Instale todas as bibliotecas necessárias: 

npm install
5
Inicie o servidor

Execute o comando para iniciar a aplicação: 

npm run dev
6
Acesse a aplicação

Com o servidor em execução, abra o endereço abaixo no navegador: 

http://localhost:3000
Banco de dados: o projeto utiliza SQLite. O banco está localizado na pasta db, no arquivo app.db. Preserve esse arquivo para manter os dados existentes.
Encerrar o servidor: para parar a aplicação, volte ao terminal e pressione Ctrl + C.

Funcionalidades

  • Listagem das vagas cadastradas.
  • Pesquisa de oportunidades pelo título.
  • Visualização dos detalhes de cada vaga.
  • Cadastro de novas oportunidades.
  • Validação dos campos obrigatórios.
  • Validação do endereço de e-mail.
  • Contato com a empresa por e-mail.
  • Identificação de vagas publicadas nos últimos 7 dias.
